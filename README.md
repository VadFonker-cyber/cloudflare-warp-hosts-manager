Интерактивная утилита для массового управления хостами в **Cloudflare WARP tunnel** на Windows.

## Зачем это нужно?

Cloudflare WARP позволяет настраивать туннели для маршрутизации трафика определённых доменов через WARP. Ручное добавление десятков доменов через `warp-cli` — утомительно. Этот скрипт автоматизирует процесс: один файл со списком доменов, одно меню — добавляйте и удаляйте хосты пакетно.

## Возможности

- ✅ **Пакетное добавление** хостов из файла в WARP tunnel
- ✅ **Пакетное удаление** хостов из WARP tunnel
- ✅ **Просмотр** текущего списка хостов в WARP
- ✅ **Просмотр** содержимого файла с доменами
- ✅ **Пропуск дубликатов** — уже добавленные хосты не обрабатываются повторно
- ✅ **Статистика операций** — отчёт об успешных, пропущенных и ошибочных операциях
- ✅ **Поддержка комментариев** в файле `hosts.txt` (строки начинающиеся с `#`)

## Требования

- **Windows** (7/8/10/11)
- Установленный и настроенный **[Cloudflare WARP](https://1.1.1.1/)**
- Доступная команда `warp-cli` в командной строке
- Включённая функция **WARP Tunnel** (доступна в определённых тарифных планах)

## Быстрый старт

1. **Скачайте** содержимое репозитория в любую папку
2. **Отредактируйте** `hosts.txt` — добавьте нужные домены (по одному на строку)
3. **Запустите** `warp-tunnel-hosts.bat` двойным кликом

## Использование

После запуска откроется текстовое меню:

```text
Cloudflare WARP -- Tunnel Host Manager
----------------------------------------
Файл: hosts.txt

[1]  Добавить все хосты (пропустить уже добавленные)
[2]  Удалить все хосты (пропустить отсутствующие)
[3]  Показать хосты в WARP (tunnel host list)
[4]  Показать содержимое файла
[5]  Выход
```

### Описание операций

| Опция | Описание |
|-------|----------|
| **1** | Прочитать `hosts.txt` и добавить все домены в WARP tunnel. Уже существующие хосты пропускаются. |
| **2** | Удалить все домены из `hosts.txt`, которые зарегистрированы в WARP tunnel. Отсутствующие пропускаются. |
| **3** | Вывести текущий список хостов, зарегистрированных в WARP. |
| **4** | Вывести содержимое `hosts.txt` на экран. |
| **5** | Завершить работу. |

## Формат файла `hosts.txt`

```
# Это комментарий — будет пропущен
example.com
sub.domain.org
ya.ru

# Пустые строки тоже игнорируются
kinopoisk.ru
```

### Правила оформления

- Один домен на строку
- Строки, начинающиеся с `#`, считаются комментариями и игнорируются
- Пустые строки игнорируются
- Пробелы в доменах не допускаются

## Пример вывода

После добавления хостов скрипт покажет статистику:

```text
Добавлено: 42   Уже было: 10   Ошибок: 0   Комментариев: 3
```

## Как это работает

1. Скрипт считывает `hosts.txt` построчно
2. Получает текущий список хостов через `warp-cli tunnel host list`
3. Сравнивает каждый домен из файла с уже зарегистрированными
4. Выполняет **добавление** или **удаление** только для новых/существующих хостов
5. Выводит подробный отчёт по каждой операции

## Источник доменов

Все домены в `hosts.txt` взяты из проекта **[v2fly/domain-list-community](https://github.com/v2fly/domain-list-community)** — открытого репозитория с актуальными списками доменов для популярных сервисов. Это гарантирует полноту и актуальность списка.

## Вклад в проект

Если вы хотите добавить домен в `hosts.txt`, но не хотите редактировать файл вручную — создайте **Issue** в этом репозитории:

1. Перейдите во вкладку **Issues** → **New Issue**

## Устранение неполадок

### `[ОШИБКА] Файл не найден: hosts.txt`

Убедитесь, что `hosts.txt` находится в той же папке, что и `warp-tunnel-hosts.bat`.

### `warp-cli` не распознаётся как команда

- Убедитесь, что Cloudflare WARP установлен и добавлен в PATH
- Попробуйте запустить скрипт из командной строки с полным путём к `warp-cli`

### Ошибки при добавлении хостов

- Проверьте, что функция WARP Tunnel активна в вашем аккаунте
- Убедитесь, что WARP запущен и авторизован (`warp-cli status`)
- Некоторые домены могут быть недоступны для добавления в tunnel
